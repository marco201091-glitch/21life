# 21Life 9.2.1

- Fixed live-game resume. Eliminated players can reopen their active game or start another one, and the game lookup now uses only the active, non-eliminated participation instead of an arbitrary historical row.
- A transient session/token refresh no longer re-runs the live-game bootstrap and drops a running tracker back to the playgroup. The web tracker also ignores transient empty catalog reads and only leaves the page on a real initial load.
- Malformed or legacy live-game state is normalized before rendering, so a missing counter or commander-damage map cannot break the table.
- The web tracker setup wizard now fits phone and tablet screens: the seat board is capped to the viewport height, the seat editor moves beside it on wider screens, and Back/Next/Start stay reachable in a sticky action bar.

## Italiano

- Corretta la ripresa della partita live. I giocatori eliminati possono riaprire la partita attiva o iniziarne un'altra; la ricerca usa solo la partecipazione attiva e non eliminata, non una riga storica arbitraria.
- Un aggiornamento transitorio di sessione/token non riavvia più il bootstrap della partita né riporta il tracker alla playgroup. Il tracker web ignora le letture transitoriamente vuote del catalogo e lascia la pagina solo al caricamento iniziale reale.
- Lo stato della partita malformato o legacy viene normalizzato prima del rendering: un contatore o una mappa di danno da comandante mancanti non rompono più il tavolo.
- Il wizard del tracker web ora si adatta a telefoni e tablet: la board dei posti è limitata all'altezza della viewport, l'editor si affianca sugli schermi più larghi e Indietro/Avanti/Avvia restano raggiungibili in una barra azioni fissa.
