## 21Life 9.1.2

- Registered players can select **Occasional deck** for borrowed or one-off decks in live setup, manual match recording and existing match editing.
- Player identity and results remain associated with the account. Occasional decks stay in the arena's match history, outside the personal collection and profile mastery.
- Replacing a previously recorded personal deck with an occasional deck refreshes historical deck details and recalculates the previous deck's statistics. Selecting a personal deck again is supported.
- Occasional creation supports commander/partner selection and optional bracket. Creation requires connectivity; failed requests retain the form and retry safely without duplicate decks. Created deck IDs and game snapshots remain compatible with offline tracking and Recovery Center.

English remains the default; Italian is available. No guest account is created for a registered player. Existing application identifiers, signing identity, domains and saved-game storage formats remain unchanged.

Update the existing installation to preserve local recovery games. Web: https://app.21life.win. Signed Android APK and Obtainium updates use GitHub Releases; unsigned production IPA uses Expo for compatible TrollStore Lite installations. Native build number: 90102.
