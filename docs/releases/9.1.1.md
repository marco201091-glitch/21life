## 21Life 9.1.1

- Restored the compact game editor. Player replacement choices open on demand; selected decks and winner follow the replacement.
- Recovery Center shows sync progress and the actual error, with retry available after stalled network requests.
- Synchronization retries recover partially acknowledged mutation batches without applying life changes twice, and acknowledge actions that became no-ops after another client changed the server state.

Update the existing installation to preserve pending local games, then use **Sync now** in Recovery Center. Do not discard a pending game or uninstall the app before it has synchronized.

Web app: https://app.21life.win. Android: signed APK and Obtainium updates through this repository, with the existing production application ID and signing identity. An unsigned production IPA is built separately on Expo for compatible TrollStore Lite installations.

The domains introduced in 9.1.0 remain in use. Existing accounts, backend data and local recovery storage formats are preserved. SHA-256 and SBOM assets accompany the APK release.
