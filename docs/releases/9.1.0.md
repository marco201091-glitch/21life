## 21Life 9.1.0

21Life moves to its new home: https://21life.win, with the web app at https://app.21life.win.

- English is the default language; Italian remains available.
- Clearer life gain/loss feedback and improved arena animations, respecting reduced motion.
- The profile automatically selects the deck with the highest mastery score (games played + twice the wins).
- iPad damage management follows the attacking player's card orientation.
- Guest management uses a single native modal host, preserves forms on errors and handles sharing failures.
- Updated web/mobile tooling and expanded regression and integration checks.

Android: install the signed APK below, or use Obtainium with this GitHub repository. The application ID and signing identity remain compatible with the previous production release.

An unsigned production IPA is built separately on Expo for compatible TrollStore Lite installations. This is an unsigned artifact, not an App Store release.

The production backend is https://supabase.21life.win. Existing accounts and data are preserved; legacy endpoints remain compatible for installed clients.

The attached SHA-256 file verifies the APK download. SBOM assets document the web and Android dependencies.
