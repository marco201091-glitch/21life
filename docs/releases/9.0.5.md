# 21Life 9.0.5

- In the game wizard, every arena member can refresh another member’s public Archidekt Commander decks when that player has sync enabled. The selected player’s phone can be offline.
- Synchronization uses fresh data, follows all catalog pages and explicitly reports completed, partial or failed updates. Retry is available; unchanged decks count as a successful update.
- Existing decks remain available when Archidekt is unavailable. Arena membership and sync preferences are checked before saving.
- Update the mobile app to use the new synchronization flow. Older versions remain supported.

## Italiano

- Nel wizard ogni membro dell’arena può aggiornare i mazzi Commander pubblici Archidekt degli altri, se hanno il sync abilitato, anche con il loro telefono offline.
- Dati aggiornati, tutte le pagine del catalogo, esiti completato/parziale/fallito e pulsante per riprovare. Anche i mazzi già aggiornati danno esito positivo.
- Se Archidekt non risponde, i mazzi esistenti restano disponibili. Appartenenza all’arena e consenso al sync vengono ricontrollati prima del salvataggio.
- Aggiorna l’app per usare il nuovo flusso. Le versioni precedenti restano supportate.
